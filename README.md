# Smart Vaccine Distribution and Inventory Management Platform

## Project Description
A web application to manage vaccine inventory,
stock availability, expiry dates and distribution.

## Technologies
- React
- Node.js
- Express.js
- MongoDB
- Git
- Docker

## Features
- Vaccine inventory management
- Add vaccine details
- Monitor vaccine quantities
- Track expiry dates
- View inventory records

## Docker Execution
docker compose up --build -d

## Application URL
http://localhost:3000
